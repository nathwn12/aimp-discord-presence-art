# aimp-discord-presence-art
Cover art for the AIMP Discord Rich Presence, art only, no code.

Companion assets for the presence client. The repo names no
consumer repository, so there is no link to give here.

`covers/` holds 149 track covers named `<64 hex chars>.jpg`
plus a `black.png` fallback used when a track has no art.
`assets/` holds one house footer file (`signature.svg`).

To swap a cover, replace its file in place under the same name.
Shipped covers are `.jpg` files, most square at 500 or 512 px
on a side, and the fallback is a 600 by 600 `.png`.

MIT, see `LICENSE`.
